# Power BI Sales Analysis Dashboard
## 📊 Project Overview
This project presents an interactive Sales Analysis Dashboard
developed using Microsoft Power BI.
The dashboard provides a detailed analysis of sales, profit,
units sold, orders, products, customers, cities, and time-based
sales performance.
The objective of this project is to transform raw sales data into
meaningful business insights using Power BI.

## 🎯 Project Objectives
- Analyze overall sales performance
- Monitor total sales, profit, units and orders
- Identify top-performing products
- Identify top customers based on sales
- Compare sales performance across cities
- Analyze sales trends by year and quarter
- Analyze the relationship between sales and profit
- Compare product performance
- Provide an interactive business dashboard
  
## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Excel
- Data Cleaning
- Data Modeling
- Data Visualization

## 📌 Key Performance Indicators
The dashboard contains the following KPIs:
- Total Sales
- Total Units
- Total Profit
- Total Orders

## 📈 Dashboard Visualizations
The dashboard includes:
1. Top 5 Products by Sales
2. Top 5 Customers by Sales
3. Sales by City
4. Sales by Year and Quarter
5. Sales vs Profit by Product
6. City-wise Sales and Profit Table
7. Top/Bottom Product Analysis

## 🔍 Business Analysis
The dashboard helps identify:
- Best-performing products
- Highest-value customers
- Cities generating higher sales
- Sales trends over time
- Products generating higher profit
- Relationship between sales and profit
- Overall business performance
